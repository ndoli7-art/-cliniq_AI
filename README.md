# 🏥 CliniQ AI - Smart Patient Intake & Emergency Triage System

**CliniQ AI** is a healthcare triage and queue management web platform designed to eliminate waiting room disorder, prioritize critical emergency patients dynamically, and streamline clinical intake workflows.

---

## 🌟 Key Features

* **📲 Patient Check-In Kiosk:** Allows patients to self-register and complete a rapid emergency symptoms screening.
* **🚨 Dynamic Emergency Priority Queue:** Automatically intercepts critical symptoms (e.g., chest pain, respiratory distress) and moves emergency patients to the top of the queue.
* **🩺 Doctor & Consultant Dashboard:** Provides real-time queue visibility and automatically generates **SOAP pre-consultation notes** based on intake data.
* **📢 Waiting Room TV Display:** Live, high-visibility queue board showing active ticket calls and upcoming patients.

---

## 🛠️ Tech Stack

* **Frontend & Backend:** Python, Streamlit
* **Data Processing:** Pandas
* **Deployment:** Streamlit Community Cloud
